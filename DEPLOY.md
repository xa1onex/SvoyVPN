# Инструкция по развертыванию изменений miniapp

## Что нужно сделать на сервере:

### 1. Загрузить все файлы на сервер
Убедитесь, что загружены ВСЕ файлы из папки `miniapp/`:
- `miniapp/index.html`
- `miniapp/need/app.css` (новый файл!)
- `miniapp/need/app.js`
- `miniapp/need/assets/index.css`
- `miniapp/need/assets/sprite.svg`
- `miniapp/need/fonts/*` (все шрифты)
- `miniapp/need/libs/*` (все библиотеки)

### 2. Перезапустить сервер
После загрузки файлов **обязательно перезапустите сервер**:
```bash
# Если используете systemd
sudo systemctl restart ваш-сервис

# Или если запускаете вручную
# Остановите старый процесс и запустите заново
```

### 3. Очистить кеш браузера
В Telegram:
- **Android/iOS**: Закройте приложение Telegram полностью и откройте заново
- **Desktop**: Нажмите Ctrl+Shift+R (или Cmd+Shift+R на Mac) для жесткой перезагрузки

Или откройте miniapp в обычном браузере и:
- Нажмите F12 (открыть DevTools)
- Правой кнопкой на кнопку обновления → "Очистить кеш и жесткая перезагрузка"

### 4. Проверить, что файлы доступны
Откройте в браузере (замените YOUR_DOMAIN на ваш домен):
- `https://YOUR_DOMAIN/miniapp/need/app.css?v=2` - должен показать CSS
- `https://YOUR_DOMAIN/miniapp/need/app.js?v=2` - должен показать JS
- `https://YOUR_DOMAIN/miniapp/need/assets/sprite.svg` - должен показать SVG

### 5. Проверить логи сервера
Если что-то не работает, проверьте логи сервера на наличие ошибок:
```bash
# Пример для systemd
sudo journalctl -u ваш-сервис -f

# Или если логи в файле
tail -f /path/to/logs/server.log
```

## Что должно быть видно после обновления:

1. **Нижняя панель навигации** с тремя кнопками: VPN, Setup, Profile
2. **Кнопка "Оплатить"** должна быть внизу страницы, не уезжать вверх
3. **Иконка звездочки** должна быть видна на популярном тарифе
4. **Все три раздела** должны переключаться через нижнюю панель

## Если ничего не помогло:

1. Проверьте, что файлы действительно на сервере:
   ```bash
   ls -la /path/to/miniapp/need/app.css
   ```

2. Проверьте права доступа:
   ```bash
   chmod -R 644 /path/to/miniapp/need/*
   ```

3. Проверьте, что сервер читает правильную папку (путь в `webhook_server.py`)

4. Попробуйте открыть miniapp в режиме инкогнито/приватном режиме браузера
