SvoyVPN — Telegram VPN бот
==========================

Новый рефакторинг бота из проекта xUmbra-1:

- Разбитие монолитного `main.py` на модули
- Упрощённая и безопасная логика подписки
- Автоматическое управление VPN-ключами на всех серверах
- Подключение по subscription-ссылке `/sub/{token}`

## Структура проекта

Будет выглядеть примерно так:

- `bot/`
  - `__init__.py`
  - `config.py` — загрузка настроек из `.env`
  - `database.py` — пул PostgreSQL и миграции схемы
  - `xui_client.py` — клиент для x-ui/3x-ui
  - `yookassa_client.py` — клиент ЮKassa
  - `flyer_client.py` — клиент Flyer (опционально)
  - `webhook_server.py` — HTTP-сервер `/sub/{token}` + вебхуки
  - `subscriptions/service.py` — бизнес-логика подписок и ключей
  - `payments/service.py` — обработка платежей, идемпотентность
  - `handlers/` — Telegram handlers (`start`, подписка, админка и т.д.)
  - `main.py` — точка входа: запуск бота и веб-сервера

Логика и данные берутся из старого проекта `xUmbra-1`, но код переписан и разделён по файлам.
