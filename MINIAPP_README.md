# SvoyVPN Miniapp

Мини-приложение для управления VPN подпиской через Telegram WebApp.

## Структура

```
miniapp/
├── index.html      # Главная страница приложения
├── css/
│   └── style.css   # Стили в темной теме с синими акцентами
└── js/
    └── app.js      # JavaScript логика и интеграция с Telegram WebApp API
```

## Экраны

1. **Главный экран** - показывает статус подписки, ссылку на подписку, кнопку выбора тарифа
2. **Экран тарифов** - выбор плана подписки (1, 3, 6, 12 месяцев) с ценами и скидками
3. **Экран оплаты** - выбор способа оплаты (Telegram Stars, ЮKassa) и количества устройств
4. **Экран настройки VPN** - инструкции по установке и настройке VPN на разных устройствах
5. **Экран профиля** - информация о пользователе, реферальная программа, транзакции

## API Endpoints

- `POST /api/user` - Получить данные пользователя и подписки
- `GET /api/tariffs` - Получить список тарифов
- `GET /api/payment-methods` - Получить способы оплаты
- `POST /api/payment/create` - Создать платеж

## Интеграция с ботом

В главной клавиатуре бота добавлена кнопка "📱 Открыть приложение", которая открывает miniapp.

URL miniapp формируется из `SUBSCRIPTION_BASE_URL` или `PUBLIC_BASE_URL` из `.env`:
```
{SUBSCRIPTION_BASE_URL}/miniapp
```

## Безопасность

Все запросы к API проверяются через верификацию `initData` от Telegram WebApp API с использованием HMAC-SHA256.

## Настройка

1. Убедитесь, что в `.env` указан `SUBSCRIPTION_BASE_URL` или `PUBLIC_BASE_URL`
2. Запустите бота - miniapp будет доступен по адресу `{BASE_URL}/miniapp`
3. Кнопка для открытия miniapp автоматически появится в главном меню бота

## Разработка

Для локальной разработки можно использовать:
```bash
# Запустите бота
python -m bot.main

# Miniapp будет доступен по адресу:
http://localhost:8080/miniapp
```
