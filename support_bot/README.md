# SvoyVPN — бот техподдержки

Отдельный Telegram-бот для тикетов, AI-ассистента (OpenAI) и режима оператора.

## Возможности

- **Тикеты** — создание, переписка, закрытие, история
- **AI** — ответы с доступом к БД, логам активности, статусу серверов, journalctl
- **Позвать человека** — очередь для операторов, уведомления staff
- **Оператор** — `/admin`, AI-режим («продли подписку user 123 на месяц»), `/reply ID текст`
- **Оценка** — после закрытия тикета шкала 1–5 и комментарий

## Переменные окружения

Добавьте в `/root/SvoyVPN/.env`:

```env
# Токен бота поддержки (@BotFather)
SUPPORT_BOT_TOKEN=

# OpenAI (не коммитьте ключ в git)
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini

# Кто может работать как оператор (по умолчанию ADMIN_IDS)
SUPPORT_STAFF_IDS=

# Логи основного сервиса для AI
SUPPORT_JOURNAL_UNIT=svoyvpn
SUPPORT_JOURNAL_LINES=80
```

Используется та же PostgreSQL, что и основной бот (`DATABASE_URL` / `DB_*`).

## Запуск

```bash
cd /root/SvoyVPN
source venv/bin/activate
python -m support_bot.main
```

## systemd (пример)

См. `svoyvpn-support.service` в корне репозитория.

## AI-инструменты (режим 🤖 ИИ)

**Чтение (25):** профиль, поиск, платежи, ключи, баланс, устройства, статистика, серверы, цены, UTM, выводы, логи, eSIM заявки…

**Запись (31):** подписка/тариф, bypass и месячный трафик, баланс, серверы, trial/referral/цены, UTM, менеджеры, объявление, eSIM beta, ключи X-UI…

Все вызовы — реальные операции в PostgreSQL (как `/admin` основного бота).

## Команды

**Пользователь:** `/start`, `/help`, `/new`, кнопки клавиатуры

**Оператор:** `/admin` → «📋 Ответы на тикеты» или «🤖 Режим ИИ»
